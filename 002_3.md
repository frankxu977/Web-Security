# Network Foundations - Network Components

这一节主要讲：

```text
一个完整的网络由哪些组件组成？
```

核心分为：

```text
End Devices
Intermediary Devices
Network Media & Software
Servers
```

---

# 1. End Devices

## End Device / Host

**终端设备（End Device）也叫 Host（主机）**

指：

> 网络中最终发送或接收数据的设备。

Examples:

```text
Computer
Laptop
Smartphone
Tablet
Smart TV
IoT Device
```

它们通常是用户直接操作的设备。

例如：

```text
Laptop
↓
Wi-Fi
↓
Internet
↓
Website
```

Laptop 就是：

```text
End Device / Host
```

主要作用：

- Generate Data
- Receive Data
- Access Network Resources
- Access Internet Services

---

# 2. Intermediary Devices

## Intermediary Device

**中间设备**

作用：

> 帮助数据从一个 End Device 到达另一个 End Device。

常见设备：

```text
Router
Switch
Modem
Access Point
```

基本结构：

```text
End Device
    ↓
Intermediary Device
    ↓
Network
    ↓
Intermediary Device
    ↓
End Device
```

它们负责：

- Packet Forwarding
- Traffic Management
- Path Selection
- Network Connectivity
- Security Controls

---

# 3. NIC

## NIC - Network Interface Card

**网络接口卡**

作用：

> 让设备能够连接网络并发送 / 接收数据。

例如：

```text
Computer
↓
NIC
↓
Ethernet Cable
↓
Network
```

或者：

```text
Laptop
↓
Wireless NIC
↓
Wi-Fi
```

NIC 可以是：

```text
Wired NIC
→ Ethernet

Wireless NIC
→ Wi-Fi
```

---

## MAC Address

每个 NIC 都会有：

```text
MAC Address
```

例如：

```text
00:1A:2B:3C:4D:5E
```

MAC Address 主要工作在：

```text
OSI Layer 2
Data Link Layer
```

用于识别本地网络中的设备。

---

# 4. Router

## Router

**路由器**

作用：

> 在不同网络之间转发 Packet。

工作层：

```text
OSI Layer 3
Network Layer
```

主要依据：

```text
IP Address
```

决定数据去哪。

例如：

```text
Home Network
      ↓
   Router
      ↓
  Internet
      ↓
Web Server
```

Router 可以：

- Connect Different Networks
- Forward Packets
- Choose Routes
- Manage Traffic
- Apply Security Rules

---

## Routing Table

Router 会使用：

```text
Routing Table
```

决定：

> 某个 IP 的数据应该往哪里发送。

简单理解：

```text
Destination IP
↓
Check Routing Table
↓
Choose Next Hop
↓
Forward Packet
```

---

## Routing Protocols

常见协议：

```text
OSPF
BGP
```

### OSPF

```text
Open Shortest Path First
```

主要用于：

> 网络内部寻找最佳路径。

### BGP

```text
Border Gateway Protocol
```

主要用于：

> Internet 上不同大型网络之间交换路由信息。

---

# 5. Switch

## Switch

**交换机**

主要作用：

> 在同一个 LAN 中连接多个设备。

工作层：

```text
OSI Layer 2
Data Link Layer
```

Switch 根据：

```text
MAC Address
```

决定数据应该发给哪个设备。

Example:

```text
PC A ──┐
PC B ──┤
Server ├── Switch
Printer┘
```

Switch 不会默认把数据发给所有设备。

它会：

```text
Read MAC Address
↓
Find Destination Port
↓
Forward Frame
```

---

# 6. Router vs Switch

这个非常重要。

```text
Switch
→ Layer 2
→ MAC Address
→ Same Network / LAN

Router
→ Layer 3
→ IP Address
→ Between Different Networks
```

简单记：

```text
Switch
→ 管局域网内部

Router
→ 管不同网络之间
```

---

# 7. Hub

## Hub

**集线器**

Hub 是一种比较老的网络设备。

工作层：

```text
OSI Layer 1
Physical Layer
```

特点：

> 收到数据以后直接广播给所有端口。

例如：

```text
        Hub
      /  |  \
    PC1 PC2 PC3
```

如果 PC1 发数据：

```text
PC1
↓
Hub
↓
PC2 + PC3 都收到
```

即使数据其实只想发给 PC2。

---

# 8. Hub vs Switch

```text
Hub
→ Layer 1
→ Broadcast to Everyone
→ 不理解 MAC Address
→ 效率低

Switch
→ Layer 2
→ Use MAC Address
→ Send to Correct Device
→ 效率高
```

因此现代网络：

```text
Switch
```

基本已经取代：

```text
Hub
```

# 14. Software Firewall

## Software Firewall

软件防火墙，也叫：

```text
Host-Based Firewall
```

安装在单独的一台设备上。

作用：

> 根据规则控制进入和离开本机的网络流量。

例如：

```text
Incoming Packet
↓
Firewall Rule
↓
Allow / Drop
```

可以控制：

```text
Incoming Connections
Outgoing Connections
Applications
Ports
Protocols
```

---

## Example: iptables

Linux 常见防火墙工具：

```text
iptables
```

例如：

```text
Incoming ICMP
↓
iptables
↓
DROP
```

意思是：

> Linux 主机直接丢弃收到的 ICMP 流量。

```text

↓ Request
```

```text

↓

↓
Web Server
↓
Process Request
↓
```

```text
Client
```

# 20. Cybersecurity Relevance

这些设备以后都会成为：

```text
Attack Surface
```

Pentester 可能检查：

```text
End Device
→ Operating System vulnerabilities

Router
→ Configuration / Routing / ACL

Switch
→ VLAN / Layer 2 attacks

Server
→ Open ports / services / vulnerabilities

Firewall
→ Filtering rules

Protocols
→ Insecure communication
```

例如：

```text
Nmap
↓
Scan Server
↓
Find IP
↓
Find Open Port
↓
Identify Service
↓
Look for Vulnerability
```

因此理解网络组件是学习：

```text
Enumeration
Nmap
Pivoting
Network Pentesting
Active Directory
```

的基础。

```text

→ 最终发送或接收数据的设备

→ 让设备连接网络
→ Has MAC Address

→ Layer 2
→ MAC Address
→ Connect devices inside LAN

Router
→ Layer 3
→ IP Address
→ Connect different networks

Hub
→ Layer 1
→ Broadcast everything

```

---

# Key Points to Remember

```text
Host = End Device

NIC = Network Interface

MAC = Layer 2

Switch = Layer 2 + MAC

Router = Layer 3 + IP

Hub = Layer 1 + Broadcast

RJ-45 = Ethernet Connector

Protocol = Communication Rules

Firewall = Traffic Control

Client → Request
Server → Response
```

---

# Most Important Comparison

```text
Hub
→ Layer 1
→ Broadcast

Switch
→ Layer 2
→ MAC
→ Same LAN

Router
→ Layer 3
→ IP
→ Between Networks
```
