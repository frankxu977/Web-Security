# Information Security Principles

## 1. CIA Triad

CIA Triad 是信息安全最核心的三个原则。

### Confidentiality
**机密性**

确保信息只能被授权用户访问。

常见实现：
- Encryption
- Access Control
- Permissions

Example:

```text
别人未经授权查看你的银行账户信息
→ Confidentiality 被破坏
```

---

### Integrity
**完整性**

确保数据没有被未经授权地修改。

常见实现：
- Hashing
- Digital Signatures
- Checksums

Example:

```text
攻击者把银行余额从 $100 改成 $10,000
→ Integrity 被破坏
```

---

### Availability
**可用性**

确保授权用户在需要时能够访问系统和数据。

常见实现：
- Backup
- Redundancy
- Disaster Recovery
- Failover

Example:

```text
网站被 DDoS 攻击导致无法访问
→ Availability 被破坏
```

---

## 2. Other Security Principles

### Authentication
**身份验证**

验证用户、设备或进程是谁。

Examples:
- Password
- Fingerprint
- Face ID
- MFA

```text
Authentication = Who are you?
Authorization = What can you do?
```

---

### Non-repudiation
**不可否认性**

确保用户不能轻易否认自己执行过某个操作。

常见实现：
- Digital Signatures
- Audit Logs

Example:

```text
用户对电子合同进行了数字签名
→ 之后不能轻易否认自己签署过合同
```

---

### Privacy
**隐私**

确保个人敏感信息被正确收集、存储和使用。

Examples:
- Data Minimization
- Consent Management
- Data Protection

```text
只收集真正需要的数据
→ Data Minimization
```

# Information Security Process

```text
Risk Assessment
      ↓
Security Planning
      ↓
Implementation of Security Controls
      ↓
Monitoring & Detection
      ↓
Incident Response
      ↓
Disaster Recovery
      ↓
Continuous Improvement
      ↺
```

## 1. Risk Assessment

识别：
- Assets
- Threats
- Vulnerabilities
- Potential Impact

目标：

```text
确定哪些安全问题最重要
↓
决定修复优先级
```

---

## 2. Security Planning

根据风险制定安全方案。

Examples:
- Security Policies
- Procedures
- Security Architecture
- Resource Allocation

Example:

```text
Risk:
员工密码太弱

Plan:
Strong Password Policy
+
Multi-Factor Authentication
```

---

## 3. Implementation of Security Controls

把安全计划真正部署到系统中。

Examples:
- Firewall
- MFA
- Encryption
- Access Control
- EDR

```text
Prevent
Detect
Respond
```

---

## 4. Monitoring & Detection

持续观察系统是否存在异常行为。

常见监控内容：
- Logs
- Network Traffic
- Login Attempts
- Security Alerts

常见工具：
- SIEM
- IDS
- EDR

---

## 5. Incident Response

发生安全事件后进行处理。

```text
Detection
   ↓
Containment
   ↓
Eradication
   ↓
Recovery
```

Example:

```text
发现恶意软件
↓
隔离设备
↓
删除恶意程序
↓
恢复系统
```

---

## 6. Disaster Recovery

重大事件发生后恢复系统和数据。

Examples:
- Backup
- Redundancy
- Failover
- Recovery Plans

```text
减少 Downtime
+
减少 Data Loss
```

---

## 7. Continuous Improvement

安全不是一次性的工作。

需要不断：
- Review
- Audit
- Patch
- Update
- Improve

```text
New Threats
+
New Vulnerabilities
+
New Technologies
↓
Security Controls must evolve
```

---

# Common Information Security Tools

## Firewall

控制进入和离开网络的流量。

```text
Incoming Traffic
      ↓
   Firewall
      ↓
Allowed / Blocked
```

---

## IDS

**Intrusion Detection System**

用于检测可疑活动。

```text
IDS = Detect
```

---

## IPS

**Intrusion Prevention System**

不仅检测攻击，还可以自动阻止攻击。

```text
IPS = Detect + Block
```

---

## SIEM

**Security Information and Event Management**

```text
Collect Logs
↓
Analyze Events
↓
Detect Suspicious Activity
```

常用于 Blue Team / SOC。

---

## Vulnerability Scanner

自动寻找系统中的潜在漏洞。

Examples:
- Nessus
- OpenVAS

```text
Scanner:
"This system MAY be vulnerable."
```

```text
Vulnerability Scanner
≠
Penetration Testing
```

---

# Penetration Testing Tools

## Nmap

Network scanning and discovery.

主要用途：
- Host Discovery
- Port Scanning
- Service Detection
- OS Detection

Example:

```bash
nmap 10.10.10.10
```

可以简单理解为：

```text
目标机器开放了哪些门？
```

---

## Wireshark

Network packet analysis.

主要分析：
- TCP
- HTTP
- DNS
- ARP
- TLS

```text
Capture Packets
↓
Analyze Network Traffic
```

---

## Burp Suite

主要用于：

**Web Application Penetration Testing**

常见功能：
- Proxy
- Intercept
- Repeater
- Intruder

```text
Browser
   ↓
Burp Suite
   ↓
Web Server
```

---

## Metasploit

**Exploitation Framework**

主要包含：
- Exploits
- Payloads
- Auxiliary Modules

```text
Find Vulnerability
↓
Select Exploit
↓
Deliver Payload
↓
Gain Access
```

---

## John the Ripper

主要用于：

**Password / Hash Cracking**

```text
Password Hash
↓
John the Ripper
↓
Attempt to recover password
```

---

# Vulnerability Scanner vs Pentester

## Vulnerability Scanner

```text
Automatic Scan
↓
Potential Vulnerability
```

通常告诉你：

```text
"This MAY be vulnerable."
```

## Pentester

```text
Find Vulnerability
↓
Analyze
↓
Exploit
↓
Verify Impact
↓
Report
```

Pentester 要证明：

```text
"This IS vulnerable,
and this is the real impact."
```

---

# Authorization

Penetration Testing 最重要的前提之一：

**Authorization**

```text
Same Tool
Same Command
Same Technique
```

但是：

```text
Authorized
→ Penetration Testing

Unauthorized
→ Potentially Illegal Activity
```

测试之前必须明确：

```text
Authorization
+
Scope
```
